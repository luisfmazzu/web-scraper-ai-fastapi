# FastAPI - Web Scraper AI


## 🚀 Quick Start

You'll need Docker and Docker Compose to run this application.

1. Build the project

```bash
docker-compose build
```

2. Start the project

```bash
docker-compose up -d
```

3. Watch logs

```bash
docker-compose logs -f app
```

## ⚙️ Local Development

```
poetry install
poetry shell
sh ./scripts/launch.sh
```
